# 纳指100 & 标普500 估值看板

S&P 500 and Nasdaq 100 valuation dashboard showing Trailing PE, Forward PE, and Shiller CAPE with over/undervaluation percentages.

## 在线预览

启用 GitHub Pages 后访问：

**https://liuyanstar.github.io/market-valuation-dashboard/**

## 如何启用 GitHub Pages

1. 打开仓库 **Settings** → **Pages**
2. Source 选择 **Deploy from a branch**
3. Branch 选 **main**，文件夹选 **/ (root)**
4. 保存后等待 1–2 分钟即可访问

## 数据说明

数据截至 2026 年 10 月底–11 月初，来源包括 GuruFocus、YCharts、Siblis Research 等。不同机构计算方法可能略有差异。

仅供参考，不构成投资建议。
